# Bawadir Construction W.L.L. — Static Website

A responsive static corporate website for Bawadir Construction W.L.L.

## Structure

- `index.html` — Home
- `about.html` — Company background and capability
- `services.html` — Services
- `projects.html` — Project portfolio with completed/ongoing filter
- `contact.html` — Contact details and enquiry form
- `config.js` — Central configuration placeholder for domain/contact/social values
- `styles.css` — Site styling
- `script.js` — Navigation/year helpers
- `projects.js` — Portfolio data
- `assets/logo.jpg` — Bawadir logo
- `assets/projects/` — Project photographs
